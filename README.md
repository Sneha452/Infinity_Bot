# 🎯 2. InfinityBot (Multifunctional Chatbot)

# 🤖 InfinityBot

A multifunctional AI chatbot capable of handling text, image, and speech inputs with intelligent responses in both text and voice formats.

---

## 📖 Description

InfinityBot is an AI-powered chatbot built using Flutter that supports multimodal interaction. It can process user inputs in text, image, and speech formats and generate dynamic responses.

The chatbot uses machine learning and NLP techniques integrated with the Gemini API to provide meaningful and contextual replies.

---

## 🚀 Features

- 💬 Text-based conversation  
- 🖼 Image input processing  
- 🎤 Speech input support  
- 🔊 Text-to-speech responses  
- 🧠 AI-powered dynamic replies  
- 🗂 Chat management (create/delete chats)  

---

## 🛠 Tech Stack

- Frontend: Flutter (Dart)  
- Backend: Gemini API  
- ML/NLP: Natural Language Processing  
- Image Processing: R-CNN  
- Tools: Android Studio
